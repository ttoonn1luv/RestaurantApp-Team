## 💻 วิธีรันโปรแกรม (How to Run)

1. เตรียมความพร้อมเครื่องมือ
   - ติดตั้งโปรแกรม Visual Studio (เวอร์ชัน 2019 หรือ 2022) 
   - ตรวจสอบว่าเลือกติดตั้งคอมไพเลอร์ .NET Desktop Development แล้ว

2. ดาวน์โหลดโปรเจกต์ลงเครื่อง (Clone)
   - เปิดโปรแกรม Terminal, Git Bash หรือ Command Prompt ในเครื่อง
   - พิมพ์คำสั่งดึงซอร์สโค้ดจาก GitHub ของทีม:
     git clone https://github.com[ชื่อยูสเซอร์ GitHub ของคุณ]/RestaurantApp-Team.git

3. เปิดโปรเจกต์
   - เข้าไปในโฟลเดอร์โปรเจกต์ที่ดาวน์โหลดมา
   - ดับเบิลคลิกเปิดไฟล์ที่มีนามสกุล .sln (เช่น RestaurantApp.sln) ระบบจะเปิดโปรแกรม Visual Studio ขึ้นมาอัตโนมัติ

4. สั่งรันโปรแกรม
   - กดปุ่ม Start (ปุ่มลูกศรสีเขียว) ด้านบนโปรแกรม 
   - หรือกดคีย์ลัด Ctrl + F5 บนคีย์บอร์ด เพื่อรันโปรแกรมผ่านหน้าต่าง Console

5. ขั้นตอนการทดสอบโปรแกรมตามลำดับหน้าจอ
   - ระบบจะให้ป้อนข้อมูลเพื่อเพิ่มร้านอาหารใหม่ โดยให้พิมพ์ข้อมูลแล้วกด Enter ตามลำดับ ได้แก่ "ป้อนชื่อร้านอาหาร", "ป้อนประเภท" และ "ป้อนคะแนน"
   - เมื่อป้อนข้อมูลครบ ระบบจะแสดงผลคำนวณ "คะแนนสูงสุด" และ "คะแนนต่ำสุด" ของร้านอาหารทั้งหมดในระบบทันที
   - ปิดท้ายด้วยการแสดงรายชื่อร้านอาหารที่มีคะแนนตั้งแต่ 4.5 ขึ้นไป พร้อมสรุปจำนวนร้านและค่าเฉลี่ยคะแนนรีวิวทั้งหมดออกมาบนหน้าจอ
